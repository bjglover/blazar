# v1.0.0 — BLAZAR

First public release of BLAZAR by Dog Lab Plugins.

- Windows x64 VST3 instrument with 40 factory programs.
- Interacting MATTER, FIELD, PARTICLES and 12-model PLASMA synthesis.
- Custom resizable interface, MIDI expression, tempo pulse and user patch banks.
- Procedural synthesis; no external samples required.

Install: extract and copy the entire `Blazar.vst3` folder into `C:\Program Files\Common Files\VST3`, then rescan your host.

No standalone application or legacy Quasar state migration is included.
